# Sentinel AI

Plataforma de observabilidad, diagnóstico (RCA) y reparación asistida por IA.

Este repositorio lo desarrolla de forma autónoma **AI Software Factory** (Autopilot), un ítem del backlog por rama `factory/sentinel-ai/NN-...`, con PRs en draft para revisión humana. La especificación está en [`docs/SPEC.md`](docs/SPEC.md).

- `backend/`: API de Sentinel, con FastAPI y SQLAlchemy. Las dependencias están en `backend/requirements.txt`.
- `frontend/`: dashboard, con React, TypeScript, Vite y Tailwind.
- `demo-app/`: aplicación de demostración con fallas intencionales.

Las instrucciones para ejecutar la aplicación se completan durante el desarrollo.
